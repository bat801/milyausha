# Milyausha Nurieva — teacher portfolio

Статический сайт-портфолио учителя английского и немецкого языков.
HTML5 + CSS3 + Vanilla JavaScript, без фреймворков и без серверной части.
Сайт рассчитан на размещение на GitHub Pages.

## Быстрый запуск

Так как переводы и галерея загружаются через `fetch()`, открывать `index.html` двойным щелчком недостаточно. Запустите локальный HTTP-сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000/
```

Чтобы проверить поведение, близкое к GitHub Pages (сайт в подпапке), запустите сервер из родительской папки:

```powershell
cd ..
python -m http.server 8000
```

и откройте `http://localhost:8000/milyausha/`.

## Как заменить фотографию

Замените файл:

```text
assets/img/photo_teacher.jpg
```

Рекомендуемая пропорция — 4:5 (например, 800 × 1000 px), формат JPG.
После замены при необходимости обновите `width` и `height` у изображения в `index.html`.

## Как добавить документ

1. Положите оригинал в `assets/docs/`, например `certificate_2026.pdf`.
2. Для картинки или PDF желательно сделать превью и положить его в `assets/docs/previews/`, например `certificate_2026.jpg`.
3. Добавьте объект в массив `data/documents.json`:

```json
{
  "id": 9,
  "title": {
    "ru": "Название на русском",
    "en": "Title in English",
    "ba": "Башҡортса исеме",
    "de": "Titel auf Deutsch",
    "sr": "Наслов на српском"
  },
  "category": "certificates",
  "file": "assets/docs/certificate_2026.pdf",
  "preview": "assets/docs/previews/certificate_2026.jpg",
  "year": "2026"
}
```

Доступные категории:

- `certificates` — сертификаты
- `diplomas` — дипломы
- `courses` — курсы
- `publications` — публикации

`file` может указывать на PDF или изображение. Тип определяется по расширению:

- PDF открывается в модальном окне через `<iframe>` и печатается через скрытый iframe;
- JPG/JPEG/PNG открываются как изображение, печать открывается в отдельном окне.

Порядок карточек в галерее совпадает с порядком объектов в JSON.

## Контакты

Контакты находятся в начале `js/main.js` в массиве `CONFIG.contacts`.
Сейчас используются:

- Email и WhatsApp — из резюме;
- Telegram и MAX — тот же номер телефона, что и в WhatsApp;
- VK — профиль `https://vk.ru/id68968635`.

MAX не поддерживает прямые ссылки на номер телефона: карточка показывает номер
`+7 927 963-24-94`, а кнопка открывает сайт MAX, где контакт можно найти по номеру.
Если появится прямая ссылка на профиль вида `https://max.ru/u/...`, замените `href`
у контакта `max` в `CONFIG.contacts`.

## Языки

Активные языки: русский, английский, башкирский, немецкий.
По умолчанию сайт открывается на русском. Выбор сохраняется в `localStorage`.

Сербский полностью переведён в `locales/sr.json`, но скрыт из переключателя.
Чтобы включить его в интерфейсе, раскомментируйте строку в `js/main.js`:

```js
availableLanguages: [
  'ru',
  'en',
  'ba',
  'de',
  'sr'
]
```

Для предварительного просмотра сербской версии без изменения интерфейса откройте:

```text
http://localhost:8000/?lang=sr
```

## Печать

- **PDF** — скрытый iframe + `iframe.contentWindow.print()`.
- **Изображение** — отдельное окно с изображением и `window.print()`.
- **Резервный вариант** — если браузер блокирует всплывающее окно или печать PDF, сайт предлагает открыть документ в новой вкладке.

Разрешите всплывающие окна для сайта, если браузер их блокирует.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий `bat801/milyausha`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.
5. Сохраните настройки.

Сайт будет доступен по адресу:

```text
https://bat801.github.io/milyausha/
```

Все пути в проекте относительные, поэтому сайт корректно работает в подпапке GitHub Pages.

## Примечания

- Внешние библиотеки не используются. Подключаются только шрифты Google Fonts.
- Иконки — встроенный SVG-спрайт в `index.html`.
- Для корректной работы `fetch()` нужен HTTP-сервер; это ограничение браузеров, а не сайта.
- Папка `_forOpenCode/` содержит исходные материалы и исключена из git через `.gitignore`.
